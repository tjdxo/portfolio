On-Device VLM Optimization

Efficient High-Resolution Visual Input for Edge AI

Academic Project · 2026.03–2026.06

서울시립대학교 전자전기컴퓨터공학종합설계 / SW 산학협력 프로젝트

실험 이미지 준비 중

작업 현장 인식을 위한 Jetson Orin Nano 환경의 VLM 입력 효율화를 실험했습니다. 질문과 관련된 영역만 고해상도로 선택해 정확도와 연산 비용의 균형을 살펴봤습니다.

연구 질문
고해상도 입력은 작은 객체 인식에 유리하지만 visual token, 추론 시간과 메모리 사용량이 늘어납니다. 전체 이미지를 고해상도로 처리하지 않고도 필요한 세부 정보와 주변 맥락을 유지할 수 있는지 확인했습니다.
실험과 구현
해상도별 정확도·token·latency·메모리 및 연산 비용을 비교하고, object crop과 wider crop의 맥락 손실을 살펴봤습니다. GRID / sliding-window로 후보 영역을 생성하고 CLIP similarity로 질문 연관도를 계산해 순위를 매긴 뒤, 선택한 고해상도 영역과 저해상도 전체 thumbnail을 함께 입력하는 pipeline을 구현했습니다.
관찰한 결과
1280px 축소 실험에서는 token 수가 원래의 약 35.8%, 추론 시간이 약 26.2%로 줄었지만 정확도도 약 7.4% 감소했습니다. 영역 선택 방식은 비슷한 token budget의 720px 저해상도 입력 대비 VStar 약 +10.4%, HRBench 약 +10.0%의 정확도 개선을 실험에서 확인했습니다. TreeBench의 개선은 제한적이었고, crop 수를 늘리면 token과 추론 비용이 다시 증가했습니다.
배운 점
모델 크기뿐 아니라 입력 표현과 visual token 구성이 성능에 영향을 준다는 점을 확인했습니다. 단순 축소의 정보 손실과 crop의 맥락 손실을 함께 고려하며, 정확도·latency·메모리·token cost 사이의 trade-off를 실험하고 benchmark 결과를 분석했습니다. 많은 crop보다 작업에 필요한 영역을 효율적으로 선택하는 것이 중요했습니다.

Speaker Verification

화자 인증 방식의 발전과
짧은 발화 환경에 대한 탐구

OpenLab · 연구 / 학습 진행 중

배경
짧은 발화에서는 화자를 구분할 정보가 제한됩니다. 이러한 환경에서 발생하는 성능 저하와 pooling·context 문제를 중심으로 화자 인증을 학습하고 있습니다.
탐구 내용
i-vector와 PLDA에서 d-vector, TDNN 기반 x-vector, SSL 기반 방식으로 이어지는 흐름을 살펴보고 있습니다. Text-dependent / Text-independent 조건의 차이와 DNN embedding이 발화 정보를 표현하는 방식을 탐구합니다.
현재 관심 주제
Short utterance 환경에서 pooling과 문맥 정보가 화자 표현에 미치는 영향을 이해하는 데 집중하고 있습니다.

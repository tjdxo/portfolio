On-Device VLM Optimization

Efficient High-Resolution Visual Input for Edge AI

Academic Project · 2026.03–2026.06

서울시립대학교 전자전기컴퓨터공학종합설계 / SW 산학협력 프로젝트

실험 이미지 준비 중
배경
Jetson Orin Nano 환경에서 고해상도 이미지의 세부 정보를 유지하면서 VLM의 token·추론 시간·메모리 비용을 줄이는 방법을 실험했습니다.
참여 내용
해상도와 crop 방식별 성능을 비교하고, GRID / sliding-window 후보를 CLIP으로 순위화해 질문 관련 영역을 선택했습니다. 저해상도 전체 thumbnail과 선택한 고해상도 crop을 결합하는 입력 pipeline을 구현했습니다.
결과
비슷한 token budget의 720px 입력 대비 VStar 약 +10.4%, HRBench 약 +10.0%의 정확도 개선을 실험에서 확인했습니다. TreeBench의 개선은 제한적이었으며, crop 증가에 따른 비용을 비교하면서 정확도와 연산량의 trade-off를 분석했습니다.

Python / Qwen3-VL / CLIP / Jetson Orin Nano / Edge AI / Region Selection

Speaker Verification

화자 인증 방식의 발전과
짧은 발화 환경에 대한 탐구

OpenLab · 연구 / 학습 진행 중

배경
짧은 발화에서는 화자를 구분할 정보가 제한됩니다. 이러한 환경에서 발생하는 성능 저하와 pooling·context 문제를 중심으로 화자 인증을 학습하고 있습니다.
참여 내용
i-vector와 PLDA에서 d-vector, TDNN 기반 x-vector, SSL 기반 방식으로 이어지는 흐름을 살펴보고 있습니다. Text-dependent / Text-independent 조건의 차이와 DNN embedding이 발화 정보를 표현하는 방식을 탐구합니다.
진행 상황
Short utterance 환경에서 pooling과 문맥 정보가 화자 표현에 미치는 영향을 이해하는 데 집중하고 있습니다.

Speaker Verification / DNN Embedding / SSL / Short Utterance
